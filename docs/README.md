| `card.png` | A single card clicked open, showing repo, branch, time, turns and tokens | In "What you get" |

## Taking them

- Crop to the page content. Never capture the browser window: the address bar shows
  `file:///Users/<you>/...` and your tabs and bookmarks would be in frame.
- Make the browser roughly 1400px wide first. On a retina display that gives a ~2800px
  image, which stays sharp in GitHub's ~880px content column.
- PNG, ideally under 500KB each.
- Use fake data. `standup` renders whatever history you have, and the real thing contains
  the opening message of every session you have ever run.

Once a file is in this folder, uncomment the matching line in the main README.
